# BookingSystem

A Spring Boot-based movie theater ticket booking platform with integrated Razorpay payment processing, JWT authentication, and optimistic locking for concurrent seat reservations.

**Key Features:**
- 🎬 Movie & Show Management
- 🪑 Real-time Seat Booking with Concurrency Control
- 💳 Razorpay Payment Integration
- 🔐 JWT Authentication & Authorization
- ⏰ Automatic Booking Expiration (5-minute reservation timeout)
- 🔄 Optimistic Locking for Race Condition Prevention

**Tech Stack:** Java 25 • Spring Boot 4.0.7 • PostgreSQL • JWT • Razorpay API
